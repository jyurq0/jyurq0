## What I'm working on

**The Slatch.** An alarm clock you can't turn off from bed. To dismiss it you have to go tap NFC tags you've placed around the room, and if you ignore it, it escalates. I'm also prototyping a BLE wearable that vibrates to wake you up and stays in sync with the alarm.

Built with React, FastAPI, PostgreSQL, NFC, BLE, Docker

**NoRegrets.** Lets someone leave messages, photos and videos for the people they love, delivered after they pass away. The hard part is making sure it never fires by mistake, so it needs several signals before it releases anything: SMS check-ins through Twilio, passive activity, and confirmation from more than one emergency contact. Even then the release is delayed and can be reversed. Contacts can confirm a release without being able to read what's in it, and everything is encrypted at rest and in transit.

Built with Python, Flask, React, PostgreSQL, Twilio, Docker
